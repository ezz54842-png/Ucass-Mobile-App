# UCAS Services — Flutter

تطبيق خدمات جامعية عربي RTL مستوحى من الهوية البصرية للكلية الجامعية للعلوم التطبيقية.

## ما يتضمنه التطبيق

### الطالب
- لوحة رئيسية وملخص اليوم
- الخدمات الجامعية والبحث والتصنيف
- تقديم الطلبات وتتبعها
- الجدول الدراسي
- تفاصيل المساقات
- العلامات والمعدل
- الخطة الدراسية
- الحضور والغياب
- الامتحانات
- الخدمات المالية
- البطاقة الجامعية الرقمية QR
- الإعلانات والإشعارات
- حجز المواعيد
- الدعم والتذاكر
- الملف الشخصي

### عضو هيئة التدريس
- لوحة المدرس
- المساقات والجدول التدريسي
- قائمة الطلبة والملف الأكاديمي
- تسجيل الحضور
- إدارة العلامات
- نشر إعلانات المساق
- استقبال طلبات الطلبة واعتمادها أو إرجاعها
- الإرشاد الأكاديمي
- الحجوزات والدعم

### الموظف
- لوحة الموظف
- الحضور والانصراف
- طلب الإجازة
- كشف الراتب
- المستندات
- المهام
- الطلبات الواردة وإجراءات المعالجة
- الحجوزات والدعم والإشعارات

## التشغيل

```bash
flutter pub get
flutter run
```

## إنشاء APK

```bash
flutter build apk --release
```

أو ارفع المشروع إلى GitHub. ملف `.github/workflows/build-apk.yml` موجود وجاهز، وسيبني APK تلقائياً.

## مهم
هذه النسخة كاملة من ناحية واجهات وتجربة الاستخدام والسيناريوهات وتعمل ببيانات تجريبية محلية. الربط الحقيقي مع نظام الجامعة يحتاج API/Backend وقاعدة بيانات ومصادقة وصلاحيات وإشعارات حقيقية. تم تجهيز بنية التطبيق بحيث تكون مناسبة لهذه المرحلة التالية.
